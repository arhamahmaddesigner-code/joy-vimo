# JOY VIMO — Android QA App

Private Android-first development repository. The approved purple JOY VIMO visual direction is the product target. This repository builds **internal testing APKs only**. It does not publish to Google Play or Apple App Store.

## Current delivery scope
- On-device focus goals, optional daily use budgets and simulated opening restrictions
- Home, Focus Shield, Joy Feed, Progress, Reset and Settings views
- Local-only demo state
- Android app usage measurement is a separate native permission feature, not device-wide app blocking

## Build
Open the repository Actions tab and see **Android QA APK**. Successful runs upload an installable APK artifact. The artifact must be tested on Realme C71. No store-release signing keys are stored in this repository.
